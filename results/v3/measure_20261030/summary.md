## 확인한 것
- 10건 모두 오류 없이 끝까지 진행, 시트 형식 첫 시도 10/10 통과
- 과장 표현: 입력 10개(P07 6 · P10 4) → 결과(시트·템플릿) 0개. 결과에는 "합격 보장 대신 인사팀 8년 경험", "확인된 내용과 아직 확인되지 않은 내용을 구분"처럼 사실로 바꿔 씀
- 근거 인용 138개 모두 입력과 일치 (어제 P02에서 있었던 한 글자 변형은 이번엔 0건)

- 짧은 답(P05 "강원도 감자", P06 "맛있는 쿠키"): 추가 질문이 예시와 함께 나옴

## 측정 중 발견해 고친 것
1. **실제 사이트 AI 호출 전부 서버 오류** (10/30 새벽 과장 점검 추가 때 생김) → 수정·배포 후 실제 사이트에서 정상 확인 (`677f8d2`)
2. **컬러 0안 (10건 중 3건)** → 같은 입력으로 다시 6번 요청하면 모두 정상 → 앱에서 0안이면 한 번 더 자동 요청 (`0e87e59`). 첫 실패 원문은 저장하지 않아 정확한 원인은 확실하지 않음
3. **과장 규칙 오탐** → "주름 사라짐,"을 쉼표째 따로 셈(7개 → 6개), "합격 보장 표현을 빼고 / 합격 보장 대신"처럼 피하라는 안내를 과장으로 셈(1개 → 0개)
