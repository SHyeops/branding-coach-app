# From Your Garage — 질문으로 찾는 내 브랜드

> 차고에 앉아 스스로에게 묻듯 보기를 고르다 보면, "내가 원래 생각하던 게 이거였구나"를 한 장의 **브랜드 아이덴티티**로 정리해 주고, 바로 쓸 문구와 시작 채널까지 알려주는 1회 코칭 앱입니다.
> AI 네이티브 커리어 캠프 2기 1차 프로젝트 (마케팅 직군)

- 실제 사이트: https://fromyourgarage.vercel.app (AI 호출, 비용 발생)
- 테스트 사이트: https://fromyourgarage-test.vercel.app (예시 답만, 비용 0원)
- 결과 예시 바로 보기: https://fromyourgarage.vercel.app/?demo=report · 답이 채워진 장면부터: `?demo=scenes`

## 1. 어떤 문제를 푸나요
소상공인·1인 창업자는 하고 싶은 건 있어도 "왜, 누구에게, 무엇이 다른지"를 말로 정리하기 어렵습니다. 마케터인 제가 직접 브랜드 브리프를 써 보니 1개에 평균 **24.5분**이 걸렸고, 미션·메시지에서 막히고 근거 없는 주장을 쓰기도 했습니다 (`20261028_지표측정기록_v1.md`).
AI에게 한 번에 물으면 그럴듯하지만 "내 것 같지 않은" 결과가 나옵니다. 이 앱은 결과를 대신 써 주기보다 **내 안의 생각을 끄집어내는 순서**와 **근거가 보이는 결과**에 집중합니다.

## 2. 사용 흐름 (약 15분, 미측정)
1. **기본 정보** — 상품/서비스, 이름, 한 줄 설명
2. **GARAGE DAY 1 (장면 6개)** — "그런데 나… 이걸 왜 시작하려는 거지?" 같은 혼잣말 질문에 속마음 보기를 고름. 고를 때마다 차고 벽에 포스트잇이 붙고 전구가 켜짐
3. **간판** — 성향 4쌍과 말투 고르기 → "아이디어 ON!"
4. **확인** — AI가 이해한 내용을 보고 맞아요 / 고칠 점 입력
5. **브랜드 아이덴티티** — 유형·고객·미션·메시지·슬로건·말투·판매 전략·컬러·할 일 등 13개 항목. 항목마다 '상세'에서 **왜 이렇게 나왔는지와 근거가 된 내 선택**을 확인하고, 미션·슬로건은 여러 안 중 직접 고름
6. **활용 템플릿** — 인스타그램·스레드·스마트스토어·블로그·당근용 문구를 복사

함께 있는 메뉴: **브랜드 스토리**(작게 시작한 브랜드 10곳) · **1:1 멘토링**(가상 멘토, 첫 1회 무료 예시)

## 3. 설계 판단 (마케터 관점)
- **주관식 → 보기 고르기:** 다 주관식이면 지루하고 결과를 믿기 어렵다는 사용자 피드백 → 큰 틀(보기) 안에서 고르고, 필요한 곳만 한 줄 더 쓰게 함
- **정답처럼 말하지 않기:** 미션·메시지는 2안, 슬로건은 3안을 보여 주고 사용자가 고름
- **AI가 정하지 않는 것:** 브랜드 유형(6가지)은 고른 보기로 앱이 계산 → 같은 선택이면 늘 같은 결과. 시작 채널은 정해진 목록 안에서만
- **읽고 끝이 아니라 바로 씀:** 결과를 채널별 문구로 바꾸는 활용 템플릿으로 연결

## 4. 안정성
| 방어 | 방법 |
|---|---|
| 빈 입력·고르기 누락·개수 초과 | 다음 단계로 못 넘어가고 안내 |
| 너무 짧은 답 | AI가 예시를 들어 한 번 더 질문 |
| 지어낸 근거 | AI가 "내 답"이라며 인용한 문장을 실제 입력과 자동 대조해 불일치 표시 |
| 과장 표현 | 효능·질병 단정, 성과 보장, 근거 없는 최상급, 지나친 단정 4유형을 규칙으로 점검 (비용 0원, 같은 글이면 같은 결과) |
| 플랫폼 지어내기 | 시작 채널은 정해진 목록 안에서만 |
| AI 실패·형식 오류 | 앱이 멈추지 않고 안내 + 다시 시도 |

## 5. 수치로 확인
실제 AI로 테스트 10건을 돌린 결과 (2026-10-30, `results/v3/measure_20261030/summary.md`)

| 지표 | 결과 |
|---|---|
| 과장 표현 걸러낸 수 | 입력 10개(콜라겐 젤리 6 · 이력서 코칭 4) → 결과 0개 |
| 근거 인용 일치율 | 138개 중 138개 (100%) |
| 시작 채널 목록 지키기 | 10건 중 10건 |
| AI 처리 시간 | 한 건 평균 70.9초 |

메인 지표(내 생각에 더 가깝나, 생각 정리 점수)는 실제 사용자 측정 예정이며, 결과는 측정 후 추가합니다. 자세한 내용: `20261030_브랜딩앱_기획_v11.md` 5절

## 7. 직접 실행하기
```bash
git clone https://github.com/SHyeops/branding-coach-app.git
cd branding-coach-app/web
cp .env.local.example .env.local   # OPENAI_API_KEY, OPENAI_MODEL 입력 (값은 큰따옴표). 비용 없이 보려면 FAKE_AI="1"
npm install
npm run dev                        # http://localhost:3000
```
- 기술: Next.js 15 (App Router) + OpenAI API, 배포는 Vercel (`main`에 push하면 자동 배포)
- API 키는 서버(`web/app/api/ai/route.ts`)에서만 쓰이고 브라우저로 나가지 않습니다
- 루트의 `app.py`는 첫 버전(Streamlit)으로, 백업용으로 남겨 두었습니다
